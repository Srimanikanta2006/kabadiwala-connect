# Structured Datasets & Seed Data
**Platform:** Kabadiwala Connect (RE:LINK)

This directory contains the seed datasets required by the problem statement:
- [`seed_materials.json`](seed_materials.json): Material categories with bilingual labels, CPCB codes, and base rate ranges.
- [`seed_recyclers.json`](seed_recyclers.json): CPCB/MPCB registered recyclers with GPS coordinates, accepted items, and offered rates.
- [`seed_prices.json`](seed_prices.json): Daily scrap mandi benchmarks and trend indicators.
